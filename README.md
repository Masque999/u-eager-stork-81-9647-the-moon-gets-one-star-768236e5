# The Moon Gets One Star

One line, 1-120 characters: a one-star review of the moon.

Entry: `One star for the moon: beautiful, but it never answers, and it keeps waking me up at 3 a.m. just to look pretty.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
